# 우리집 약 점검 (교육용 시제품)

여러 병원·약국에서 받은 약을 함께 먹어도 되는지, 한국의약품안전관리원 DUR 정보로 점검하는 도구입니다.
**진단·처방 도구가 아닙니다.** 결과와 상관없이 약사·의사와 상담하세요.

## 실행 방법

1. 파이썬 3.10 이상 설치
2. 이 폴더에서 터미널을 열고 필요한 라이브러리 설치
   ```
   pip install -r requirements.txt
   ```
3. 앱 실행 (브라우저가 자동으로 열립니다)
   ```
   streamlit run app.py
   ```
4. 테스트 실행 (선택)
   ```
   python test_check.py
   ```

API 키나 회원가입은 필요 없습니다.

온라인 실행 링크: (배포 후 여기에 주소를 적으세요)
잠든 앱 화면이 나오면 **"Yes, get this app back up!"** 버튼을 누르고 1~2분 기다리세요.

## 예시 입력

| 생년월일 | 약 | 기대 결과 |
|---|---|---|
| 19520315 | 클래리시드건조시럽125mg + 조코나정20밀리그램 | 병용금기 1건 |
| 19520315 | 노바스크정5밀리그람 + 넥스디핀정2.5mg | 효능군 중복 1건 |
| 19520315 | 쎄레브렉스캡슐100밀리그램 | 노인주의 1건 |
| 19760101 | 노바스크정5밀리그람 + 다이아벡스엑스알서방정500밀리그램 | 문제 없음 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 화면 (Streamlit) |
| `check.py` | 점검 로직 (병용금기, 동일성분 중복, 효능군 중복, 노인주의) |
| `report.py` | 약사에게 보여줄 확인표(HTML) 만들기 |
| `test_check.py` | 자동 테스트 |
| `prepare_data.py` | 원본 DUR CSV → `data/` 정제 |
| `download_pill_info.py` | 식약처 낱알식별 API → `raw/낱알식별.csv` (API 키 필요, 최초 1회) |
| `prepare_pill_images.py` | 낱알식별 → `data/pill_images.csv` (사진 주소·모양) |
| `explain.py` | 쉬운 설명 카드 찾기 (`data/explanations.csv`) |
| `data/` | 정제된 데이터 |

## 데이터 출처

한국의약품안전관리원 DUR 정보 (병용금기 2026-07-31, 효능군중복주의·노인주의 2026-07-21 기준).
비상업적 연구·교육 목적으로만 사용할 수 있습니다.

알약 사진·모양: 식품의약품안전처 의약품 낱알식별 정보 (공공데이터포털). 사진 파일은 저장하지 않고 식약처 서버 주소로 불러옵니다.
